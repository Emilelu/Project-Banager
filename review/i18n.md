### 翻译原则（已执行）

- **key 一一对应，零缺项零多项**：双向差集为空（`en\zh = ∅`、`zh\en = ∅`，ja 同理）。
- **英文**：祈使/名词短语做按钮（`Save`、`Add Show`、`Export Backup`、`Restore Backup`）；产品语言按要求固定为
  `nav.watching = Watching`、`nav.remaining = Waiting`、`nav.watched = History`。不用机翻腔，用 `shows updating this month`、`Clear this year`、`No shows yet — add your first show or import from Excel to get started` 这类地道表达。
- **日文**：ます/です体与体言止め混用，贴合日本动漫工具习惯——`nav.watching = 視聴中`、`nav.remaining = 更新待ち`、`nav.watched = 視聴履歴`；按钮用「保存/編集/クリア/別の壁紙にする」这类短句；提示语用「〜してください」「〜しました」。
- **emoji 全保留**：🖼️ 💾 ✨ ✏️ 🗑️ 💣 ⏳ 📺 🎲 🧊 💧 🔄 📌 🔗 ⬇ ↺ 📂 🎨 🏠 🔍 ▶ ⚠️ ✓ ✗ 在 en/ja 中逐条保留，是设计语言的一部分。
- **占位符原样**：`{count}` `{name}` `{date}` `{days}` `{message}` `{year}` `{added}` `{failed}` `{list}` `{done}` `{total}` `{percent}` `{n}` 一个不改名、不翻译、不丢失。`showDialog.episodeTokenHint` 里的 `{集数}` 是**业务层占位符**（由 `useEpisode` 在拼 URL 时替换），中文源包用中文写法，en/ja 译文改写为「episode token」的叙述以免误导，同时不破坏该 token 的语义。
- **语言自称不译**：`lang.zh = 简体中文`、`lang.ja = 日本語` 在三语包中保持原样（用户需要能认出自己母语），仅 `lang.en = English`。测试对 `lang.*` 做了汉字豁免。

## 2. 设计决策

### 2.1 `src/locales/index.js`（新建）

集中出口，避免「第四个真相」：

- `dictionaries = { zh, en, ja }`：给测试与工具统一取源。
- `registerAllMessages()`：按 `SUPPORTED` 顺序注册三语，可重复调用（`registerMessages` 是浅合并）。
- `keyCounts()`：自检/报告用，不参与运行时。
- **导入即注册**：模块顶层调用一次 `registerAllMessages()`，兼容 `import './locales'` 的写法，任何入口拿到文案都不会退回兜底。

`main.js` 走 `registerAllMessages()` 显式注册，两步顺序是 **先注册语言包 → 再 `initLocale()`**，这样首帧渲染时 `t()` 已有完整文案，不会闪一下裸 key 或中文。

### 2.2 `useI18n.js` 的兜底修正（唯一一处引擎改动）

原 `FALLBACK_ZH` 是手抄的 11 条最小常量，漏一条就退化到裸 key。改为直接引用完整源包：

```js
import zhMessages from '../locales/zh.js'
const FALLBACK_ZH = zhMessages
```

- 无循环依赖：`zh.js` 是纯数据对象，不 import 任何东西。
- 解决的真实问题：组件单测（`tests/a11y.test.js`、`tests/watching.test.js` 等）只挂组件、不 `import './locales'`，原来的 11 条常量撑不住 `watching.addShow` 之类的 key，界面文字会变成裸 key。改成整包兜底后这些老用例全部恢复。
- 回退链未变：**当前语言 → zh → 原样返回 key**，语义与文档一致。

### 2.3 响应式策略

`tt` 保持普通函数（不改造成 `computed`，避免每次调用新建 computed 的开销）。模板里凡调用 `tt()` 的位置都会在渲染期读取 `currentLocale.value`，因此 `setLocale` / `toggleLocale` 直接触发重渲染，无需手动订阅。已用探针组件验证两条路径：

1. 模板直接 `{{ tt('nav.watching') }}` → 切换后立即变。
2. `computed(() => { void locale.value; return tt('...') })` → 同样响应（对需要在 computed 里组合多段文案的页面，这是推荐写法，注意必须先读一次 `locale.value` 建立依赖）。

### 2.4 顶栏语言按钮

- 形态：文字轮换 **中 → EN → 日 → 中**（`localeLabel`），不用 emoji、不用新图标，与顶栏已有的内联 SVG 极简风格统一。
- 显示的是**点击后会切换到的目标语言**，而不是当前语言，避免「看着中文按钮不知道点了会怎样」。
- `aria-label` / `title` 都走 `tt('lang.switch')`，随语言变。
- 点击调用 `toggleLocale()`（`SUPPORTED = ['zh','en','ja']`，环形推进）。

### 2.5 时钟的星期本地化

顶栏时钟原来写死 `['日','一','二','三','四','五','六']` + `周` 前缀。改为 `Intl.DateTimeFormat(locale, { weekday: 'short' })`：

- zh → `周六`，en → `Sat`，ja → `土`，切语言即时跟随。
- `try/catch` 兜住老环境无 `Intl` 的情况（退化为不显示星期，不崩）。
- 数字部分固定 `YYYY/MM/DD`，不随语言变（避免误读）。
