# 🔴 严重问题

## V-01 追番页顶部空玻璃横条

工具栏按钮移到顶栏后，容器留下了但内容空了。

- 实测：`.glass` 高 **30px**、`textContent = ""`、`children.length = 0`、可交互元素 **0**
- 同页其它 `.glass` 都有内容（页头 49px / 6 个可交互元素）
- 空数据与有数据时都存在，空数据时更显眼
- **建议**：删掉该容器

## V-02 标签徽章被压缩

- 实测 8 个徽章中 **6 个** `scrollWidth > clientWidth`：
  - `悬疑` 宽 **15px**，需 25px（缺 10px）
  - `热血`/`科幻` 宽 22px，需 25px（缺 3px）
  - 仅 2 个正常（27px）
- 截图可见被裁成「科…」或只剩半字
- **建议**：`shrink-0` + `whitespace-nowrap`，或超过 2 个折叠为「+N」

## V-03 1024px 窄屏下表格溢出视口

**这是本轮新发现。**

- 实测（1024×768 视口）：等待更新页表格右边界到 **1210px**，超出视口 **186px**
- 越界元素 5 个：`TABLE` / `THEAD` / `TR` / `TH` / `TBODY`
- 后果：右侧「备注」列被裁，长备注文字直接断在屏幕外（见 `1024-remaining.png`）
- 其它 5 页在 1024 下均无溢出
- **建议**：给表格容器加 `overflow-x-auto`，或按断点隐藏「备注」列

## V-04 清空弹窗三按钮溢出卡片边界

- 实测：弹窗宽 **462px**，三按钮宽 **67 / 167 / 266px**，合计 500px + 间距 → 溢出
- 截图可见：左「Cancel」左缘出框、右「Clear all records…」右缘被裁
- **建议**：按钮改 `flex-1` 等分，或长文案改短（「清空全部」）

## V-05 周五表头背景色丢失

- 实测：7 个表头只有**周五** `backgroundColor = rgba(0,0,0,0)`，其余 6 天 `rgba(...,0.15)`
- 根因已定位：`DAY_THEMES[4]` = `bg-[#D97706]/18`，**`/18` 不在 Tailwind 默认透明度刻度**（只有 5/10/20/25…），class 被静默丢弃
- **建议**：改 `/15` 或 `/20`

# 🟡 中等问题

## V-06 侧栏分区标题字号过小

- 实测：「番单」「设置」= **9.625px**（`text-[0.6875rem]`），色 `rgb(83,97,116)`
- **建议**：提到 11px，并加深一档

## V-07 卡内番剧名可用宽度异常

- 实测同一行三张卡：`星际牛仔` 名称区 **48px**（需 56px）→ 截断；`攻壳机动队…` **129px**（需 234px）→ 截断；`命运石之门` 98px（需 98px）→ 刚好
- 根因：名称与标签同处一个 flex 行抢宽度，名称缺 `flex-1 min-w-0`
- **建议**：名称独占一行，或加 `flex-1 min-w-0` + 标签 `shrink-0`

## V-08 行分隔线对比不足

- 实测：`borderBottom = 1px solid rgba(255,255,255,0.1)`
- 浅色壁纸上几乎不可见，行与行粘连
- **建议**：提到 `0.18` 或改主题色低透明

## V-09 深色模式表头渐变出现色带断层

- 实测（`dark-remaining.png`）：`thead` 紫→琥珀横跨整行，中间有可见色阶跳变
- **建议**：深色下改单一低透明底色，不做双色渐变

## V-10 年份菜单分隔线过粗过白

- 实测：分隔线用 `border-white/20`，在浅色菜单面板（`rgba(255,255,255,0.82)`）上显得突兀
- 截图可见两条粗白线把菜单切成三段
- **建议**：改 `rgba(0,0,0,0.06)` 或 `border-white/10`

## V-11 标签管理「内置」徽章字号偏小

- 实测 **8.75px**（`text-[0.625rem]`），低于 10px 可读下限
- **建议**：提到 10.5px

## V-12 导入卡片留白过多

- 实测：导入卡片高 **107px**、导出卡片 **99px**，但导入卡内只有 1 个按钮
- 目测按钮上方空白偏大
- **建议**：减少卡片上下 `py`，或补充说明文字

# 🟢 轻微问题

## V-13 主题页色圆与右侧按钮基线差 1px

- 实测：6 个色圆 y=**286** 高 35px；「跟随壁纸取色」按钮 y=**287** 高 34px
- 视觉上圆点略偏上
- **建议**：给容器加 `items-center`，或色圆改 34px

## V-14 集数行与百分比间距不自然（目测）

截图中 `e 1 / 24` 与 `4%` 之间空隙大于其它间距，进度条起点不在同一基线。未量化。

## V-15 七种星期底色不协调（目测）

紫/橙/青/绿/琥珀/褐/红同时出现，饱和度偏高。

实测底色：
`rgba(139,92,246,.15)` `rgba(249,115,22,.15)` `rgba(14,165,233,.15)` `rgba(16,185,129,.15)` `透明(V-05)` `rgba(120,113,108,.15)` `rgba(239,68,68,.15)`

- **建议**：统一为「工作日同色 + 周末强调」两档，或全部降到 8%

## V-16 深色模式说明文字对比偏低（目测）

深色下多处 `text-gray-400/500` 与深底对比不足。未逐一测比值。

## V-17 顶栏图标无自定义焦点环（目测）

Tab 聚焦时只有浏览器默认环，与全站圆角风格不匹配。
