## 🔴 确认问题（有实测数据）

### V-01 追番页顶部有一条空玻璃横条

把工具栏按钮移到顶栏后，容器留下了，但里面已经空了。

- 实测：`.glass` 高 **30px**、`textContent` 为 `""`、`children.length = 0`、可交互元素 0 个
- 对比：同页其它 `.glass` 都有内容（页头 49px 高、含 6 个可交互元素）
- 影响：贯穿整宽的空白条，看起来像渲染失败
- 建议：删掉该容器

### V-02 卡内标签徽章被压缩

- 实测 8 个徽章中 **6 个 `scrollWidth > clientWidth`**：
  - `悬疑` 宽 **15px**，需要 25px（缺 10px）
  - `热血`/`科幻` 宽 22px，需要 25px
  - 只有 2 个正常（27px）
- 影响：标签文字被裁成「科…」或只剩半字
- 建议：`shrink-0` + `whitespace-nowrap`，或超 2 个折叠为「+N」

### V-05 周五表头背景色丢失

- 实测：7 个表头里 **周五 `backgroundColor = rgba(0,0,0,0)`**，其余 6 天均为 `rgba(...,0.15)`
- 根因已定位：`DAY_THEMES[4]` 写的是 `bg-[#D97706]/18`，**`/18` 不在 Tailwind 默认透明度刻度**（只有 5/10/20/25…），该 class 被静默丢弃
- 建议：改 `/15` 或 `/20`（与其它 6 天一致）

### V-08 侧栏分区标题字号过小

- 实测：「番单」「设置」都是 **9.625px**（`text-[0.6875rem]`），色 `rgb(83,97,116)`
- 影响：全大写后更难读，且低于常用 10px 可读下限
- 建议：提到 11px 或 10.5px，并加深一档颜色

### V-09 卡内番剧名可用宽度异常

- 实测同一行内三张卡片：
  - 「星际牛仔」名称区 **48px**（文字需 56px）→ 截断
  - 「攻壳机动队 STAND ALONE COMPLEX」**129px**（需 234px）→ 截断
  - 「命运石之门」98px（需 98px）→ 刚好
- 根因：名称与标签在同一 flex 行抢宽度，名称没有 `flex-1 min-w-0`，宽度被标签挤到 48px
- 建议：名称独占一行，或 `flex-1 min-w-0` + 标签 `shrink-0`

### V-11 行分隔线对比不足

- 实测：`tbody tr` 的 `borderBottom` 是 `1px solid rgba(255,255,255,0.1)`
- 影响：浅色壁纸上几乎不可见，行与行粘连
- 建议：提到 `rgba(255,255,255,0.18)` 或用主题色低透明

### V-26 深色模式表头渐变出现色带断层

- 实测（`dark-remaining.png`）：`thead` 从紫到琥珀横跨整行，中间有可见色阶跳变
- 建议：深色下改用单一低透明底色，不做双色渐变
