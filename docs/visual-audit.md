# 🔴 严重

## V-01 追番页顶部空玻璃横条
- 实测（有数据 & 空数据均存在）：高 **30px**、`textContent=""`、可交互元素 **0**
- 同页其它卡片都有内容（49 / 565 / 200px）
- **建议**：删掉该容器

## V-02 标签徽章被压缩
- 实测 8 个中 **6 个** `scrollWidth > clientWidth`：`悬疑` **15px**/需 25px；`热血`/`科幻` 22px/需 25px
- **建议**：`shrink-0` + `whitespace-nowrap`，或超 2 个折叠「+N」

## V-03 1024px 窄屏表格溢出
- 实测（1024×768）：表格右边界 **1210px**，超视口 **186px**；越界 5 元素
- 其它 5 页在 1024 下均无溢出
- **建议**：容器 `overflow-x-auto`，或断点隐藏备注列

## V-04 1920 宽屏列宽冗余 1467px
实测（1920×1080）表格 1630px：

| 列 | 列宽 | 内容需 | 冗余 |
|---|---|---|---|
| # | 72 | 7 | 65 |
| 番剧名称 | 412 | 62 | 350 |
| **预计日期** | **554** | **51** | **503** |
| 链接 | 296 | 37 | 259 |
| 备注 | 296 | 6 | 290 |

- 「预计日期」554px 只放 `2026/01`（51px）
- 根因：无 `table-layout: fixed` 与列宽约束
- **建议**：关键列定宽（日期 120 / 链接 200），备注吃剩余

## V-05 768 极窄屏顶栏标题换行挤压

**本轮新发现，比 1024 更严重。**

- 实测（768×1024，侧栏固定 210px，正文仅 558px）：
  - 「等待更新」标题被挤成**两行**（「等待更」/「新」）
  - 右上日期「2026/11/02 周一」被截断成「2026/11/02 周」+「一」
  - 表格横向溢出，越界元素 **5 个**
  - 最右「备注」列完全不可见
- 其余 5 页在 768 下无溢出
- 根因：顶栏左侧（标题+计数+5 个动作图标）与右侧（3 图标+日期）在 558px 内放不下，且都不允许收缩
- **建议**：
  1. 768 以下把侧栏折叠为图标模式（当前仍占 210px）
  2. 顶栏动作图标在窄屏收起为「更多」菜单
  3. 表格容器加 `overflow-x-auto`（与 V-03 同一处修改）

## V-06 清空弹窗按钮溢出卡片

# 🟡 无障碍

## V-22 prefers-reduced-motion 仅覆盖 3% 动画

开启系统「减弱动态效果」后，只有壁纸过渡和导航项动画会停，其余全部照常播放。

- 实测（`reducedMotion: 'reduce'` 环境）：
  - `matchMedia('(prefers-reduced-motion: reduce)').matches = true` ✅
  - 但示例过渡 `transition: opacity 0.5s` 的实际 duration 仍是 **0.5s**，未归零
- 源码统计：`style.css` 有 **56 条 transition + 10 条 animation = 66 条**动画声明
- 但 `@media (prefers-reduced-motion: reduce)` **只有 2 处**：
  - L171：壁纸 `body.with-bg::before` 过渡
  - L504：`.nav-item` 过渡与 transform
- **覆盖率约 3%**

仍在播放的动画包括：弹窗 0.4s spring、菜单 0.32s、Toast 进出场、壁纸缩放 0.8s、按钮 hover 缩放。

- 影响：前庭功能障碍用户对大幅位移/缩放敏感，这是真实无障碍缺口
- **建议**：加一条全局兜底

```css
@media (prefers-reduced-motion: reduce) {
  *, ::before, ::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

# 建议顺序

按「影响面 × 改动量」排，同批次可一次改完。

## 第一批 · 布局结构性缺陷（P0）

同一个根因，一起修才能彻底：

- **V-03** 1024 窄屏表格溢出 + **V-04** 1920 列宽冗余
  → 表格加 `table-layout: fixed` + 关键列定宽 + 容器 `overflow-x-auto`
