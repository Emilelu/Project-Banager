🟡 无障碍
V-22prefers-reduced-motion 仅覆盖 3% 动画
  • 实测（reducedMotion: 'reduce' 环境）：matchMedia 匹配为 true ✅，但示例过渡 opacity 0.5s 的实际时长仍是 0.5s，未归零
  • 源码统计：style.css 有 56 条 transition + 10 条 animation = 66 条动画声明
  • 但 @media (prefers-reduced-motion: reduce) 只有 2 处（L171 壁纸过渡、L504 导航项）
  • 覆盖率约 3%。仍在播放：弹窗 0.4s spring、菜单 0.32s、Toast 进出场、壁纸缩放 0.8s、按钮 hover 缩放
  • 影响：前庭功能障碍用户对大幅位移/缩放敏感，这是真实无障碍缺口
  • 建议：加一条全局兜底
@media (prefers-reduced-motion: reduce) { *, ::before, ::after { animation-duration: 0.01ms !important; animation-iteration-count: 1 !important; transition-duration: 0.01ms !important; scroll-behavior: auto !important; } }
