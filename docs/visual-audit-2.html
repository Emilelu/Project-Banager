② 浏览器缩放近似（css-zoom / viewport-only）

Ctrl+= 实测（冒烟内自动探测，按 Control+= 与 Control+Add 前后对比）：devicePixelRatio 1→1、innerWidth 1440→1440 零变化，headless 下不生效 → 走 CSS zoom 近似（默认 css-zoom：html{zoom:level} + 视口 resize 为 W/1.25×H/1.25 补偿）。实测语义（探针 tmp/_probe-zoom.mjs 可复跑）：① innerWidth=1152，媒体查询与真实缩放一致；② getBoundingClientRect 值已含 zoom 因子（=屏幕物理像素）：aside.app-sidebar 210→262.5=210×1.25；③ fixed-px 元素渲染确实放大：注入 200px 洋红探针条，截图像素实测 200→250 物理px；④ 已知局限：flex/grid 均分元素在 root 空间被 fixed-px 兄弟挤占，物理尺寸小于真实 125% 缩放——.day-head-0 实测 119.28px vs 真实约 158.6px（126.9×1.25），故另提供 setZoom(level,{mode:'viewport-only'})：纯视口补偿不写 zoom，CSS-px 几何与真实缩放完全一致、gBCR 无需换算，适合纯布局/溢出审计；css-zoom 适合看放大观感。reload 后 lib 在 domcontentloaded 自动重放 zoom 样式；resetZoom(=setZoom(1)) 实测恢复 1440/169.42。全部写进 README 第 6 节。
